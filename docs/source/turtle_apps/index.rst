The turtle_apps Package
=======================

The *turtle_apps* package is located in the following source folder:

.. code-block::

   src/turtle_apps

It contains library modules that implement methods to support interactive Turtle
graphics applications:

+-------------+----------------------------------------------+
| File Name   | Contents                                     |
+-------------+----------------------------------------------+
| turtdraw.py | Interactive wrapper over the TI Turtle class |
+-------------+----------------------------------------------+

These modules are not intended to be run standalone and don't provide user interfaces.
Instead, they provide implementations that can be called from separate UI implementations.
